# CientificFlow

App web para aprender la tabla periódica: tabla completa de 118 elementos, vista por columnas, valencias, tarjetas de estudio, quiz y progreso.

## Funciones
- Tabla periódica completa sin scroll, con búsqueda y filtros por familia
- Valencias de todos los elementos (las de la tabla de clase y las más comunes del resto)
- Elegir qué estudiar: elemento a elemento o por columnas
- Tarjetas de estudio (Lo sé / Repasar) y quiz de 5 modos
- Progreso, XP, nivel y racha diaria (se guarda en el dispositivo)
- Instalable como app (PWA) y funciona sin conexión
